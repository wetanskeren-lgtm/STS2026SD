Setup Firebase Rules

Langkah pertama: atur akses database agar bisa menyimpan data

1

Buka Firebase Console

Klik tombol di bawah, lalu login dengan akun Google yang sama saat membuat project

Buka Firebase Console
2

Ganti Rules dengan Kode Ini

Hapus semua isi editor, lalu paste kode berikut:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
3

Klik "Publish Changes"

Tombol biru di atas kanan editor. Tunggu hingga status berubah menjadi "Rules deployed successfully"

4

Klik Tombol Di Bawah Ini

Untuk memeriksa koneksi dan melanjutkan ke aplikasi
