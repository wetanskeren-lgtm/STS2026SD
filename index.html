Setup Firebase Rules

Langkah pertama: atur akses database

0

Aktifkan Realtime Database (wajib utk gambar)

Console → Build → Realtime Database → Create Database (test mode) → tab Rules, ganti dengan rules aman berikut (hanya folder gambar yang terbuka):

{

  "rules": {

    "gambar": { ".read": true, ".write": true },

    "images": { ".read": true, ".write": true },

    "_ct_test": { ".read": true, ".write": true },

    ".read": false,

    ".write": false

  }

}
Buka Realtime Database

Terakhir: salin URL database Anda ke konstanta RTDB_URL di dalam kode (langkah ini hanya sekali).

1

Buka Firebase Console

Login akun Google yang sama

Buka Firebase Console
2

Ganti Rules

Hapus semua, paste:

rules_version = '2';

service cloud.firestore {

  match /databases/{database}/documents {

    match /{document=**} {

      allow read, write: if true;

    }

  }

}
